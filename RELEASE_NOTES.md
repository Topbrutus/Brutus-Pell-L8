# v1.0.1 - Brutus-Pell L8

Author: Gabriel St-Pierre  
Date: 2026-10-01

This release establishes the first isolated public release of the Brutus-Pell L8 formulation in this project.

It includes:

- the L8 exact-rank statement and derivation;
- explicit domain boundaries for q = 2 and composite q = 9;
- the exact 828-digit Q_47;
- the 36-digit prime factor `424675575059690484579658261789171649`;
- independent verification that its Pell entry rank is exactly `2209 = 47^2`;
- the 792-digit remaining-cofactor fingerprint;
- a reproducibility script using Python and SymPy 1.14.0;
- citation and Zenodo-ready metadata.

Priority note: this release creates a dated public record of the L8 formulation and q = 47 witness. It does not claim novelty for classical Pell/Lucas sequence facts or an exhaustive literature priority search.
